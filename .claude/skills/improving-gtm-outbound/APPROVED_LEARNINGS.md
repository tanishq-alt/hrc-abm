# Approved Learnings — Append-Only Ledger

This file records every improvement that has been approved, applied, and committed.
It is maintained by `promote_learning.py` and the human reviewer.
Never delete entries. If a learning is superseded, add a `superseded_by` line.

Format per entry:
```
## vNNN — {Short description}
- **Date**: YYYY-MM-DD
- **Reviewer**: Name
- **Proposal file**: data/learning/proposals/vNNN_*.yaml
- **File changed**: engine/xxx.py
- **Parameter**: exact parameter name
- **Before**: old value
- **After**: new value
- **Estimated lift**: X.X% meeting rate improvement
- **Actual lift** (if measured): TBD / X.X%
- **Superseded by**: vNNN (if applicable)
```
